# MAUL1 local forcing feasibility

Retrospective source discovery and research-only diagnostics. This package is
not connected to forecasting, Phase 6 issuance, verification, or the dashboard.

## Contents

- `source_inventory.json`: compact source metadata, observed page coverage,
  units, quality and retrieval caveats.
- `report.md`: findings, feasibility ranking, historical-analysis limits and
  prospective collection proposal.
- `usgs_acquisition.py`: bounded USGS OGC API reader. It keeps each returned
  feature intact and wraps it with retrieval time, request URL, status and a
  response hash. Provider failures are explicit.
- `coverage.py`: no-fill UTC coverage and strict pre-issue alignment functions.
- `test_feasibility.py`: fixture tests for request safety, source provenance,
  units, qualifiers, missing values and strict issue-time separation.

## Reproduce the fixture analysis

```sh
python -m unittest discover -s tests -p 'test_local_forcing_feasibility.py' -v
python -m py_compile research/local-forcing-feasibility/*.py
```

To try a current USGS retrieval when network access is available:

```sh
python research/local-forcing-feasibility/usgs_acquisition.py \
  --hours 24 \
  --output /tmp/maul1-local-forcing-snapshot.json
```

The snapshot is a research artifact. Inspect every series status, datum, units,
approval state, qualifier, cadence and source timestamp before analysis. A
successful fixture test does not demonstrate provider availability. The live
query was not run in this workspace because outbound network access was
unavailable. No observations are generated by the fixtures.
